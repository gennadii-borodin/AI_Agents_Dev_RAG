# Вопрос 04: Что нужно сделать для перевода средств?

**Команда запуска:** `python -m hybrid_rag.demo`

**Цель:** продемонстрировать работу гибридного RAG — векторный поиск (ChromaDB) + графовый обход (Neo4j) с расширением результатов по связям IMPLEMENTS/COVERS.

## Ввод

Запрос пользователя (вопрос из `QUERIES`):

> Query: Что нужно сделать для перевода средств?

## Работа программы

### 2. Гибридный контекст, переданный в LLM

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ Hybrid context sent to LLM:                                                 │
│ - [BR] BR-003: Перевод средств между счетами — предоставить пользователям   │
│ возможность переводить средства между своими счетами и сторонним            │
│ получателям                                                                 │
│ - [FR] FR-005: Перевод на свою карту — система должна позволять             │
│ пользователям переводить средства между своими счетами мгновенно и без      │
│ комиссии                                                                    │
│ - [FR] FR-006: Перевод по номеру телефона — система должна позволять        │
│ пользователям отправлять деньги другому человеку по номеру телефона с       │
│ подтверждением через SMS-код                                                │
│ - [FR] FR-007: Перевод по реквизитам — система должна позволять             │
│ пользователям переводить деньги на банковский счёт с использованием BIC и   │
│ номера счёта (IBAN)                                                         │
│ - [NFR] NFR-003: Пропускная способность — система должна обрабатывать не    │
│ менее 1000 одновременных переводов без деградации производительности        │
│ - [TS] TS-011: Перевод на свою карту — успех — пользователь переводит 500   │
│ рублей со счёта карты 1 на карту 2. Средства зачисляются мгновенно,         │
│ комиссия 0 рублей                                                           │
│ - [TS] TS-012: Перевод на свою карту — недостаточно средств — пользователь  │
│ пытается перевести сумму, превышающую баланс. Система показывает ошибку     │
│ «Недостаточно средств»                                                      │
│ - [TS] TS-013: Перевод по номеру телефона — успех — пользователь вводит     │
│ номер телефона получателя, сумму, подтверждает SMS-кодом. Перевод выполнен  │
│ - [TS] TS-014: Перевод по номеру телефона — неверный SMS-код — пользователь │
│ вводит неверный SMS-код. Система запрашивает повторный ввод, после 3 ошибок │
│ — отмена перевода                                                           │
│ - [TS] TS-015: Перевод по номеру телефона — получатель не найден — номер    │
│ телефона не зарегистрирован в системе. Система показывает сообщение         │
│ «Получатель не найден»                                                      │
│ - [TS] TS-016: Перевод по реквизитам — успех — пользователь вводит BIC и    │
│ номер счёта, сумму, подтверждает. Перевод обрабатывается в течение 1        │
│ рабочего дня                                                                │
│ - [TS] TS-017: Перевод по реквизитам — неверный BIC — пользователь вводит   │
│ несуществующий BIC. Система показывает ошибку «Неверные реквизиты банка»    │
│ - [TS] TS-030: Нагрузка на переводы — запуск 1000 одновременных переводов — │
│ все завершаются успешно без ошибок и задержек                               │
└─────────────────────────────────────────────────────────────────────────────┘
```

